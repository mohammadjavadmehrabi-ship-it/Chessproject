# بازی مار اندروید (Snake Android)

یک بازی مار (Snake) کاملاً بومی (Native Android) نوشته‌شده با Java و رندر روان ۶۰ فریم‌برثانیه روی `Canvas`، بدون نیاز به دسترسی (Permission) و قابل نصب روی اندروید ۵ تا اندروید ۱۵+.

## فایل خروجی APK
- مسیر فایل آماده نصب: `../SnakeGame.apk`
- پکیج: `com.snakestudio.snake`
- نسخه: `1.0.0` (`minSdk 21`, `targetSdk 34`)
- امضاشده با APK Signature Scheme **v1 + v2 + v3** و تراز ۴ بایتی (Zipaligned)

## ویژگی‌ها
- **۳ حالت بازی**: کلاسیک (دیوارهای بسته)، بدون دیوار (عبور از لبه‌ها)، چالشی (موانع هوشمند با تضمین دسترس‌پذیری کل صفحه با الگوریتم BFS)
- **۳ سطح سرعت**: آرام، معمولی، سریع (همراه با افزایش تدریجی سرعت با بزرگ‌تر شدن مار)
- **۳ پوسته رنگی**: نئون شب، نوستالژی (کلاسیک نوکیا/گیم‌بوی)، غروب
- **میوه طلایی جایزه** (هر ۵ سیب با تایمر حلقه‌ای و ۳۰+ امتیاز) و **سیستم کمبو**
- **حرکت فوق‌العاده روان ۶۰fps** با درون‌یابی بین خانه‌ها، افکت ذرات، لرزش صفحه، چشم‌های متحرک و زبان مار
- **افکت‌های صوتی** تولیدشده به‌صورت زنده با `AudioTrack` + دکمه قطع/وصل صدا
- **کنترل دوگانه**: کشیدن انگشت روی صفحه (Swipe با صف ۲ حرکتی برای جلوگیری از برخورد ناخواسته) + دکمه‌های جهت روی صفحه (قابل روشن/خاموش کردن) + پشتیبانی از کلیدهای جهت کیبورد
- **دو زبانه**: فارسی (پیش‌فرض با اعداد فارسی) و انگلیسی
- **ذخیره خودکار رکورد** به تفکیک هر حالت بازی در `SharedPreferences`

## ساختار پروژه
- `app/src/main/AndroidManifest.xml`
- `app/src/main/java/com/snakestudio/snake/`
  - `MainActivity.java` — چرخه حیات، پشتیبانی از Edge-to-Edge و ناچ صفحه
  - `SnakeGameView.java` — رندر ۶۰fps، منوها، افکت‌ها و کنترل لمسی
  - `GameEngine.java` — منطق مستقل و تست‌پذیر بازی
  - `SoundEngine.java` — موتور تولید صداهای بازی
  - `ThemePalette.java` — پالت‌های رنگی ۳ پوسته
  - `Strings.java` — متون فارسی و انگلیسی
- `app/src/main/res/` — آیکون‌های استاندارد (`mdpi` تا `xxxhdpi`) و Adaptive Icon
- `tests/com/snakestudio/snake/GameEngineTest.java` — تست‌های واحد موتور بازی
- `build.sh` — اسکریپت تست، کامپایل و تولید APK امضاشده
